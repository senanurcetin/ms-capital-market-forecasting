The transparent logo and X mark were copied directly from the owner's mounted Google
Drive, using files discovered through the connected Drive Logo folder. Do not redraw
the X, substitute a generated logo or distort the aspect ratio.

Core colors: midnight `#0B0F19`, deep navy `#061524`, cyan `#00E0FF`, blue `#4EA8FF`,
lavender `#8F9BFF`, violet `#6E55C6`, muted text `#B9C5CE`.
Amber is reserved for comparisons and caveats. Charts keep distinct series colors;
brand gradients do not encode model performance.

Static HTML embeds the original vector wordmark as a data URL, preserving offline
viewing without external font or image dependencies. Keep focus indicators, readable
contrast, responsive typography and source attribution visible on narrow screens.
